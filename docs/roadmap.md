# Roadmap

1. **Persistent sessions** — file-backed store so restarts don't sign everyone out.
2. **Notion page picker** — choose exactly which shared pages/databases new members can open, with permissions mirroring repo role rules.
3. **Bulk onboarding** — paste a list of teammates, apply role rules across many repositories at once.
4. **Audit log** — who invited whom, where, and when.
5. Cross-panel onboarding flow: one form → repo invite + Notion share + welcome note.

Contributions: keep the zero-dependency rule and match the design system ([DESIGN.md](../DESIGN.md)).
