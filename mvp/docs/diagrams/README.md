# Diagrams

This directory contains architecture and workflow diagrams for the SMB Access Manager MVP.

## Index

| Diagram | Description | Format |
|---|---|---|
| system-architecture | High-level system architecture | Mermaid |
| database-erd | Entity Relationship Diagram | Text-based ERD |
| auth-flow | Authentication sequence (login, session, logout) | Mermaid |
| onboarding-flow | Employee onboarding provisioning flow | Flowchart |
| offboarding-flow | Employee offboarding deprovisioning flow | Flowchart |
| github-sync-flow | GitHub OAuth and provisioning sequence | Mermaid |
| notion-sync-flow | Notion OAuth and provisioning sequence | Mermaid |
| sequence-onboarding | Full onboarding sequence with timing | Mermaid |
| sequence-offboarding | Full offboarding sequence with timing | Mermaid |
| api-overview | API endpoint overview and relationships | Graph |

All diagrams use Mermaid format for version control compatibility and GitHub rendering.
